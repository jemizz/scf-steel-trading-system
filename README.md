# SCF Steel Trading Management System

A web-based system for managing SCF Steel Trading’s inventory, sales, purchase orders, and fabrication services. This project is being developed as part of our Software Engineering course.

## Planned Features

- Product catalog that visitors can view without logging in
- Inventory tracking for products with different sizes and variants
- Walk-in sales transactions that automatically update inventory
- Fabrication details recorded as part of a sale
- Supplier and purchase order management
- Sales, inventory, and fabrication reports
- Stock replenishment, fabrication scheduling, and related product recommendations

## Project Status

In development. We are currently building the frontend; features listed above may not be functional yet.
